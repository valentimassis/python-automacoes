# Windows File Server Auditor

## Sobre o projeto

O Windows File Server Auditor é uma ferramenta desenvolvida em Python para auxiliar equipes de Infraestrutura e Segurança na análise de servidores de arquivos Windows.

O objetivo é automatizar tarefas que normalmente são executadas manualmente, como identificação de compartilhamentos, análise de permissões, cálculo de utilização de armazenamento e localização de arquivos antigos.

---

## Problema

Administradores de infraestrutura gastam muito tempo verificando manualmente:

- Compartilhamentos de rede
- Permissões de acesso
- Espaço utilizado
- Arquivos antigos
- Possíveis oportunidades de limpeza

Além de consumir tempo, esse processo está sujeito a falhas humanas.

---

## Objetivo

Automatizar a auditoria de servidores de arquivos Windows e gerar relatórios que apoiem a governança do ambiente.

---

## Funcionalidades planejadas

- Descobrir compartilhamentos do servidor
- Listar grupos e usuários com acesso
- Calcular tamanho das pastas compartilhadas
- Contabilizar quantidade de arquivos
- Identificar arquivos sem alteração há mais de X anos
- Gerar relatório em Excel
- Dashboard em Streamlit
- Geração de recomendações utilizando IA
